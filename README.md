# fuel-backend — Лабораторная работа №2

Заявочная система по курсу «Разработка Интернет Приложений» (РИП).

**Тема:** Расчёт количества теплоты в реакции горения.

| Сущность курса | Сущность предметной области |
|---|---|
| `услуга` | вид топлива (метан, пропан-бутан, ацетилен, водород) |
| `заявка` | расчёт количества теплоты в кДж, выделившейся при полном сгорании заданного объёма при н.у. (реализуется начиная с ЛР №2) |

## 2. Запуск

### 2.1. Поднять Minio и залить медиафайлы

```bash
docker compose up -d
```

### 2.2. Запустить приложение

```bash
go run ./cmd/app
```

Приложение поднимается на <http://localhost:3030> и редиректит `/` на плитку.

Переменные окружения (все необязательные):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `APP_PORT` | `3030` | порт приложения |
| `MINIO_PUBLIC_ENDPOINT` | `http://localhost:9000` | адрес Minio, из которого собираются url медиа |
| `MINIO_BUCKET` | `heat-fuel-media` | имя бакета |

### 2.3. Медиафайлы

Все изображения и видео подгружаются только из MinIO через публичный URL объекта.
Локальные файлы в проекте больше не используются: сервер не отдаёт статические
файлы из `resources`, а загрузка контента производится в бакет MinIO отдельно.

## 3. Структура проекта

Раскладка по `golang-standards/project-layout`, как в методических указаниях курса.

```
cmd/app/main.go              точка входа, минимум логики
internal/api/server.go                настройка роутера, шаблонов, статики
internal/app/models/fuel.go           модель Fuel и модель представления HeatCardView
internal/app/repository/              слой доступа к данным (коллекция в памяти)
internal/app/handler/                 слой контроллеров (три обработчика)
internal/app/storage/minio_media.go   сборка url объектов Minio по ключам
templates/                            шаблоны трёх страниц + общие блоки
resources/css/style.css               стили приложения, вынесены в отдельный файл

```

Зависимости однонаправленные: **обработчики обращаются к репозиторию,
репозиторий к обработчикам — никогда**.

## 4. Три GET-метода

| # | URL | Контроллер | Назначение |
|---|---|---|---|
| 1 | `GET /fuel_feed`<br>`GET /fuel_feed/:fuel_id`<br>`GET /fuel_feed/:fuel_id?next=true` | `FuelHandler.GetFuelFeed` | лента горения по ID топлива; из панели вкладок открывается без ID и показывает первую опубликованную карточку; с `?next=true` — следующую после указанной |
| 2 | `GET /fuel_draft` | `FuelHandler.GetFuelDraft` | получение единственного черновика для страницы добавления |
| 3 | `GET /fuel_grid`<br>`GET /fuel_grid?min_heat=50000` | `FuelHandler.GetFuelGrid` | список всех карточек плиткой + серверная фильтрация |

Роутинг объявлен в [internal/api/server.go](internal/api/server.go).

### Разбор url для вкладки Network

* `http://localhost:3030/fuel_feed/2` — `2` это `FuelID` услуги (пропан-бутан)
  в коллекции; параметр пути читается через `ctx.Param("fuel_id")`.
* `http://localhost:3030/fuel_feed/2?next=true` — `next=true` переключает
  обработчик с «показать карточку 2» на «показать следующую за 2»; читается
  через `ctx.Query("next")`. Список закольцован: после последней карточки
  открывается первая.
* `http://localhost:3030/fuel_grid?min_heat=50000` — `min_heat` это параметр
  фильтрации: нижняя граница **теплоты сгорания в кДж/м³ при н.у.**
  Фильтрация выполняется на сервере, в
  `FuelRepository.GetPublishedFuels(minHeatKJ)`. Введённое значение
  возвращается в шаблон и остаётся в поле ввода после запроса.

Фильтрация сделана по **числовому** полю по теме, а не по текстовому.
Нечисловое или отрицательное значение не роняет страницу: выводится
сообщение об ошибке, список показывается полностью.

## 5. Коллекция и статусы

Единственная модель-коллекция — `[]models.Fuel` в
[internal/app/repository/fuel_repository.go](internal/app/repository/fuel_repository.go).
Лайки хранятся вложенным массивом идентификаторов пользователей
(`LikedByUserIDs`), количество лайков **вычисляется в контроллере-обработчике**
(`len(fuel.LikedByUserIDs)` в методе `toCardView`).

| ID | Топливо | Формула | Теплота сгорания, кДж/м³ | Статус |
|---|---|---|---|---|
| 1 | Метан | CH4 | 35 800 | опубликован |
| 2 | Пропан-бутан | C3H8 + C4H10 | 108 000 | опубликован |
| 3 | Ацетилен | C2H2 | 56 000 | опубликован |
| 4 | Водород | H2 | 10 800 | опубликован |
| 5 | Бутан | C4H10 | 123 770 | **удален** — в интерфейсе не отображается |
| 6 | Метано-водородная смесь | CH4 + H2 | 30 800 | **черновик** — открывается на странице добавления |

Проверка, что удалённая карточка недоступна:
`GET /fuel_feed/5` возвращает `404` и страницу «Такого вида топлива нет в справочнике».

### Поля модели

Все поля по предметной области атомарны (1НФ): только числа, строки и даты,
никаких вложенных массивов кроме лайков.

| Поле | Тип | Смысл |
|---|---|---|
| `FuelID` | int | идентификатор |
| `FuelName` | string | название топлива |
| `ChemicalFormula` | string | химическая формула |
| `CombustionNote` | string | краткое описание реакции горения |
| `HeatOfCombustionKJ` | int | низшая теплота сгорания, кДж/м³ при н.у. |
| `IgnitionTempC` | int | температура воспламенения, °C |
| `FlameTempC` | int | температура пламени, °C |
| `AirDemandM3` | float64 | расход воздуха, м³ на 1 м³ топлива |
| `ImageKey` | string | ключ изображения в Minio |
| `VideoKey` | string | ключ видео в Minio |
| `FuelStatus` | string | черновик / опубликован / удален |
| `LikedByUserIDs` | []int | связь м-м «пользователь — топливо» |

## 6. Minio

Изображение и видео хранятся в модели **двумя отдельными полями** и содержат
только ключ объекта на латинице — не полный адрес:

```go
ImageKey: "propane_butane.jpg",
VideoKey: "propane_butane.mp4",
```

Абсолютный url собирается в
[internal/app/storage/minio_media.go](internal/app/storage/minio_media.go)
и подставляется в модель представления обработчиком:

```
http://localhost:9000/heat-fuel-media/propane_butane.jpg
```

Содержимое бакета `heat-fuel-media`:

| Ключ изображения | Ключ видео |
|---|---|
| `methane.jpg` | `methane.mp4` |
| `propane_butane.jpg` | `propane_butane.mp4` |
| `acetylene.jpg` | `acetylene.mp4` |
| `hydrogen.jpg` | `hydrogen.mp4` |
| `butane.jpg` | `butane.mp4` |
| `methane_hydrogen.jpg` | `methane_hydrogen.mp4` |

Использование url во всех трёх шаблонах:

| Шаблон | Изображение | Видео |
|---|---|---|
| `templates/fuel_feed.html` | атрибут `poster` у `<video>` | `src` у `<video>` |
| `templates/fuel_grid.html` | `src` у `<img class="heat-card__image">` | — |
| `templates/fuel_draft.html` | `src` у `<img class="heat-form__preview">` | `src` у `<video>` |

## 7. Дизайн

### Сайт-источник

<https://antonio-merloni.ru/teplotvornaja-sposobnost-razlichnyh-vidov-topliva>
— раздел «Теплотворная способность различных видов топлива», по теме работы.

### Что именно скопировано

Всё перечислено комментарием в шапке
[resources/css/style.css](resources/css/style.css).

**Три основных цвета с точными кодами:**

| Код | Роль на сайте-источнике | Роль в приложении |
|---|---|---|
| `#FD2B06` | фирменный оранжево-красный акцент: ссылки при наведении, плашки «новинка», активные пункты меню | акцент: кнопки, активная вкладка, формула, значения полей |
| `#212121` | цвет заголовков и основного текста | цвет заголовков и основного текста |
| `#FFFFFF` | фон страниц | фон страниц |

Дополнительно перенесены `#D93518` (числовые значения), `#EEEEEE` (рамки и
разделители), `#555555` (вторичный текст).

**Типографика:** Arial, заголовки жирные, в верхнем регистре, с увеличенным
межбуквенным интервалом — как в `#center_column h1` исходной темы.

**Форма карточек:** прямые углы без скруглений, рамка `1px solid #EEEEEE`,
белая подложка.

**Hover:** цвет текста и рамки уходит в `#FD2B06` за `0.15s` — как
`a.product_link:hover{color:#fd2b06}` в исходном CSS. Реализовано для карточек
плитки (`.heat-card:hover`), кнопок (`.heat-button:hover`) и вкладок
(`.heat-tabbar__item:hover`).

### Макет

Портретный режим под мобильный телефон. На широком экране «телефон»
шириной 420px центрируется, на узком занимает всю ширину.
Снизу на всех трёх страницах — панель вкладок: **Лента / Добавление / Плитка**.

### Страница «Лента» (`/fuel_feed`)

Короткое видео горения в вертикальной развёртке, проигрывается автоматически
(`autoplay muted loop playsinline`) и зациклено. Вся информация и кнопки
лежат **поверх видео**:

* название топлива и химическая формула;
* краткое описание с переключателем **Больше / Меньше** — реализован
  на чистом CSS через скрытый чекбокс и селектор `:checked ~`, **без JavaScript**;
* два поля по теме: теплота сгорания при н.у. и температура воспламенения;
* строка расчёта: сколько кДж даёт полное сгорание 10 м³ при н.у.
  (функция шаблона `heatForVolume`, зарегистрирована в `server.go`);
* иконка лайка с количеством;
* кнопка **Следующий** → `/fuel_feed/<id>?next=true`.

### Страница «Добавление» (`/fuel_draft`)

Та же информация, но поля разнесены по отдельным блокам:
отдельно изображение, отдельно видео, отдельно текст, отдельно
теплотехнические характеристики. Показывается карточка в статусе `черновик`.
По заданию ЛР №1 сохранение не реализуется — кнопка «Опубликовать» неактивна.

### Страница «Плитка» (`/fuel_grid`)

Список всех опубликованных карточек в **два столбца**. В каждой карточке:
изображение из Minio, название, теплота сгорания, количество лайков.
Сверху — поле фильтрации по теплоте сгорания. Клик по карточке открывает
ленту начиная с этой карточки (`/fuel_feed/<id>`).
